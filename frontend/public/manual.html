COO 资料收集平台 · 用户操作手册#

对应《COO 资料收集平台需求规格说明书(一期)》8.3 节交付物。 文档版本:2026-08-26 · 适用系统版本:一期(单机 Docker Compose 部署) 生产地址:https://coo.chongzhu.ai

怎么读这份手册:第 1–5 章是所有人都要看的通用部分(登录、界面、附件、流程); 第 6 章按角色分开写,只看自己那一节即可;第 7 章讲交给核查方的导出物; 第 8 章和附录是遇到问题时的速查表。

1. 开始之前#

1.1 访问地址与浏览器#

  • 浏览器打开系统地址即可使用,不需要安装任何客户端或插件。
  • 推荐 Chrome / Edge / Firefox 的近两年版本,Safari 亦可。不支持 IE。
  • 页面通过 HTTPS 访问,地址栏应显示锁形图标;若出现证书告警请勿输入密码,先联系 IT。
  • 最低适配分辨率 1366×768;手机与平板同样可用(见 1.3)。

1.2 语言切换(中文 / English / ไทย)#

右上角有语言切换按钮,三种语言随时可切:

  • 切换立即生效,不需要刷新或重新登录;
  • 选择会被记住,下次打开仍是上次选的语言;
  • 切换语言不仅换界面文字,资料包名称、部门名、工厂名也会换成对应语言(这些名称在系统里存了三语);
  • 通知内容按收件人自己的语言显示——同一条通知,中文界面看到中文、泰文界面看到泰文;
  • 早期(系统升级前)产生的历史通知没有多语言数据,会以中文原文显示,信息不会丢失。

关键词搜索是跨三语匹配的:中文界面下输入英文名一样能搜到,团队用不同语言协作不会互相搜不到。

1.3 手机与平板#

  • 屏幕较窄时,左侧菜单会自动收起;点左上角的汉堡按钮展开,菜单以浮层形式盖在内容上,点菜单项或点旁边的灰色遮罩即可收起。
  • 表格较宽时可在表格内部左右滑动查看;页面本身不会横向滚动。
  • 手机上同样可以上传附件、审核、看通知。大文件上传建议用电脑或连 Wi-Fi,并保持页面不要刷新。

1.4 两条业务线(重要)#

系统里资料有两条平行的线,操作方式一致,但入口不同:

资料包版本线客户订单线
入口「资料包」页「客户订单」页 → 进入某张订单
组织方式按 18 类 COO 资料包组织,每包可反复新建版本(V1.0、V1.1…)按客户订单组织,一张订单下挂多个资料包实例
适用场景通用的、不绑定具体订单的合规资料某一票出口订单需要随单归集的资料
归档目录…/{资料包编号}_{名称}/{版本号}/…/{资料包编号}_{名称}/{订单号}/

两条线的审核流程、锁定规则、通知、归档、导出完全一致,受控区与归档清单也同时覆盖两条线。

2. 登录与账号#

2.1 登录#

  1. 打开系统地址,进入登录页。
  2. 输入用户名与密码(用户名不是邮箱),点「登录」;在密码框直接按回车也可以登录。
  3. 登录成功后进入「工作台」。

2.2 演示账号一键登录(仅演示/验收环境)#

演示环境的登录页下方会列出全部演示账号的按钮,点一下即可用该账号进入, 便于验收时按岗位走完整流程(采购专员传料 → 工程采购经理初审 → COO 终审)。

按钮上显示的是姓名(如「工程采购经理」「财务专员」),把鼠标停在按钮上 可以看到对应的账号名与角色。停用的账号不会出现在这里。

正式环境不会显示这些按钮——系统会向后端确认这些演示账号是否真的存在且口令仍是演示值, 不存在就自然不显示,不会出现"点下去必然失败"的按钮。如果你在正式环境看到这些按钮, 说明演示账号还没停用,请立即告知管理员(见《部署与运维手册》的上线检查项)。

2.3 登录失败与账号锁定#

提示含义怎么办
用户名或密码错误账号或密码不对检查大小写、输入法;注意密码区分大小写
账号已锁定,请稍后重试连续 5 次密码错误,账号被锁 30 分钟等 30 分钟自动解锁,或请管理员重置密码立即恢复
账号已被停用,如需恢复请联系管理员账号被管理员停用联系管理员
请求过于频繁,请稍后再试同一网络出口短时间内登录请求过多(每 IP 每分钟 60 次)稍等一分钟再试;整厂共用一个出口 IP 时换班集中登录可能触发

2.4 修改密码(所有人)#

右上角头像 → 修改密码:

  • 需要填写原密码、新密码、确认新密码;
  • 新密码至少 6 个字符,两次输入必须一致,不满足会在输入框下方直接提示,提交不出去;
  • 保存后当前登录仍然有效,下次登录用新密码。

管理员重置给你的是一次性临时密码,登录后请立即在这里改成自己的密码。

2.5 忘记密码#

系统没有自助找回。联系系统管理员重置,管理员会把一次性临时密码当面/单独告知你 (该密码在管理员界面上也只显示一次)。重置后按 2.4 立即修改。

2.6 会话有效期与自动登出#

登录有效期 8 小时。过期后,任何操作(包括后台每 30 秒一次的通知刷新)都会把你带回登录页, 并在登录页顶部显示明确原因:

提示原因
登录已过期,请重新登录(未保存的内容需要重新填写)8 小时会话到期,或管理员轮换了登录密钥导致全员下线
账号已被停用,如需恢复请联系管理员你的账号在使用过程中被停用
已在其他标签页退出登录,本页已同步登出见 2.7

重要:会话过期会丢失未提交的表单内容。填写较长内容(如整改要求)前, 如果已经离开电脑很久,建议先随便点一下页面确认还在登录状态。

2.7 多标签页与共用电脑#

  • 在任一标签页退出登录,其他标签页会立即同步登出并跳到登录页,不会留下"看起来还登录着"的页面。
  • 在一个标签页换成另一个账号登录,其他标签页会自动重载并切换为新账号身份,不会用旧身份继续显示数据。
  • 工厂现场共用电脑时:用完请点退出登录,不要只关闭标签页。

2.8 退出登录#

右上角头像 → 退出登录。退出会清除本机登录凭据并记入操作日志。

3. 界面导览#

3.1 左侧菜单(按角色显示)#

菜单只显示你有权限的页面。各角色可见页面:

页面提交人部门审核人COO 终审人审计查看人管理员
工作台✓✓✓✓✓
待办任务✓✓✓—✓
客户订单✓✓✓✓(只读)✓
资料包✓✓✓✓(只读)✓
受控区—✓✓✓✓
NAS 归档——✓✓(只读)✓
操作日志———✓✓
组织管理————✓
我的导出✓✓✓✓✓
通知中心✓✓✓✓✓

通知中心不在菜单里,入口是顶栏铃铛下方的「查看全部通知」。 直接输入网址访问无权限的页面,会看到「无权访问」提示页并附返回工作台的按钮—— 这是正常的权限拦截,不是系统故障。

3.2 顶栏#

从左到右:菜单折叠按钮、通知铃铛、语言切换、头像菜单。

头像菜单里有三项:

菜单项说明
修改密码见 2.4
用户操作手册就是本文档的在线版,地址 /manual,在新标签页打开——看手册时不会丢掉当前正在填写的内容
退出登录见 2.8

手册页可直接收藏,也可用页面右上角的「打印 / 存为 PDF」存成 PDF 分发给不方便上网的同事。 左侧有章节目录,顶部的筛选框可按关键词快速定位章节。

3.3 通知铃铛与通知中心#

  • 铃铛角标显示未读数(超过 99 显示 99+),每 30 秒自动刷新一次。
  • 点击铃铛弹出最近 10 条;点某一条会标记已读并直接跳到对应的资料包或订单。
  • 下拉底部的「查看全部通知(共 N 条)」进入通知中心:分页浏览全部通知、未读高亮、支持「全部标为已读」。
  • 会收到通知的事件:资料提交待你审核、部门审核通过转呈终审、被退回、已放行归档、被撤回等。
  • 如果点通知后看到「内容不存在」的提示页,说明对应的订单/版本已被删除,通知是历史遗留,可以忽略并返回。

3.4 页面通用元素#

  • 搜索与筛选:搜索框输入关键词后点「搜索」或回车。搜索与筛选在服务端执行, 会覆盖全部数据而不只是当前这一页——在第 1 页也能搜到只存在于第 5 页的记录。
  • 分页:列表底部显示「共 N 条」并可翻页。
  • 弹窗:填完直接按回车即可提交(等同点「确定」); 在下拉框展开时回车是选中选项、在多行文本框里回车是换行,都不会误提交。 必填项没填时回车会触发校验并标红。
  • 防重复提交:提交类按钮点击后会进入 loading 状态,连点多次也只会发出一个请求。
  • 失败提示:操作失败会弹出明确的中文/英文/泰文原因(如「订单号已存在」), 弹窗不会关闭、已填内容不会丢失,改完可直接重试。
  • 时间显示:界面上的时间已换算成你本机所在时区; 导出到文件里的时间则统一带明确时区偏移(如 2026-08-23 14:51:49+07:00),便于对外举证。 截止日期是业务日期(不是时刻),不做时区换算。
  • 万一白屏:页面若出现异常,会显示带「重试 / 返回工作台」的错误提示页,左侧菜单仍然可用, 可直接切到别的页面继续工作。

4. 附件的上传、预览与下载(通用)#

4.1 允许的类型与大小#

  • 单个文件上限 100MB。
  • 允许的扩展名(白名单):
    类别扩展名
    文档.pdf .doc .docx .xls .xlsx .ppt .pptx .txt .csv
    图片.png .jpg .jpeg .gif .bmp .tif .tiff
    压缩包.zip .rar .7z
  • 空文件会被拒绝。

4.2 上传步骤#

资料包线:资料包 → 进入资料包 → 选择当前版本(或点「发起新版本」)→ 在附件区拖入或点击选择文件。 订单线:客户订单 → 进入订单 → 找到对应的资料包实例 → 在其附件区上传。

  • 支持一次多选多个文件,整批一起上传(一次多选 3 个文件就是 3 条附件记录,不会重复);
  • 上传前可在「批次号」框填写批次/订单编号(选填,最长 128 字符),会随附件一起记录并出现在归档清单里。

4.3 上传时的三道校验#

  1. 浏览器端大小预检:超过 100MB 的文件在发出去之前就被拦下,提示 「xxx.pdf 超过 100MB 上限,未上传」——不会白白上传几分钟再被拒。
  2. 扩展名白名单:不在 4.1 列表里的类型会被拒绝。
  3. 文件内容校验:系统会读取文件头,确认内容与扩展名相符。 把一个文本文件改名成 .pdf 会被拒绝并给出明确提示。 这一条是为了避免归档里出现"打不开的证据"——核查方打开时才发现不是 PDF,那份证据就等于没有。 .txt .csv 这类没有固定文件头的格式一律放行。

4.4 上传进度#

上传时附件区下方会出现实时进度条(「上传中 45%」)。 大文件上传不受常规超时限制,请耐心等待并不要刷新页面——刷新会中断上传。

4.5 相同文件只存一份#

系统按文件内容存储,同一份文件被多处引用时磁盘上只保留一份,但每处的附件记录都是独立的: 删掉其中一处不影响其他地方的下载。这对用户是透明的,不需要做任何事。

4.6 在线预览#

点附件名即可预览:

类型行为
PDF弹窗内直接翻页阅读(有页码与翻页按钮)
图片(png/jpg/gif/bmp/tif)弹窗内直接显示
文本(txt/csv)弹窗内显示文本,中文正常显示
其他(Word/Excel/PPT/ZIP 等)自动转为下载,请在本地打开

预览弹窗有高度限制并可在内部滚动,翻页按钮不会被挤出屏幕。

4.7 表格右侧的操作按钮#

各列表页(订单、资料包、附件、受控区、组织管理等)行末的操作列里是一排 图标按钮——放大镜=详情、下载箭头=下载、铅笔=编辑、垃圾桶=删除, 红色的一律是删除/停用这类不可逆操作。

  • 把鼠标停在图标上会显示它的名称,不确定就先停一下再点。
  • 操作列固定在表格右侧,左右滚动时始终可见。
  • 字段过长会截断成省略号,鼠标停上去可看到完整内容。

4.8 下载#

点附件行的「下载」按钮:

  • 下载交由浏览器自带的下载管理器处理——有进度显示、可暂停/继续、支持断点续传,大文件也不会卡住页面;
  • 点击后几乎立即就会出现在浏览器的下载列表里;
  • 下载凭据只有 60 秒有效期,且只对这一个附件、这一个人有效。 如果把下载链接复制给别人或过一会儿再打开,会失败——这是设计如此,请重新在系统里点下载;
  • 每次下载都会记入操作日志(操作人、时间、IP、文件名)。

4.9 删除附件与状态回退#

  • 草稿或已退回状态下可以随意增删附件。
  • 审核中(待部门审核 / 待COO终审)或已退回状态下重新上传或删除附件, 该条目会自动回退到「待部门审核」,原有审核结论作废——这是为了保证"审的就是最终那一版"。
  • 已放行(已锁定)的内容不能增删任何附件,只能新建版本重走流程。
  • 删除附件不影响其他地方引用的同一份文件。

5. 业务流程#

5.1 总览#

责任人上传附件
      │  提交审核
      ▼
待部门审核 ──通过──► 待 COO 终审 ──放行──► 已放行(版本锁定,只读)
   │                    │                        │
   └──退回──┐      └──退回──┐                 ├─► 进入受控区,可被审计调阅
            ▼                ▼                   └─► 参与每日 NAS 归档
        已退回(必须填写整改要求,责任人整改后重新提交)

提交人在审核完成前可撤回,修改后重新提交。

5.2 状态说明#

状态含义谁能操作
草稿未提交,可自由增删附件责任人
待部门审核已提交,等待本部门审核人处理部门审核人(通过/退回);提交人可撤回
待COO终审部门已通过,等待 COO 终审COO 终审人(放行/退回);提交人可撤回
已放行COO 终审通过,版本锁定只读,进入受控区并参与 NAS 归档任何人都不能再改;只能新建版本
已退回审核未通过,附带整改要求责任人整改后重新提交
已撤回提交人主动撤回责任人修改后重新提交

5.3 版本与锁定#

  • 版本号自动生成:V1.0 → V1.1 → … → V1.9 → V2.0,保证唯一且递增,不会重复。
  • 一旦放行,该版本永久锁定为只读,任何人不能修改、不能删除、不能增删附件。
  • 需要变更已放行的内容:新建版本,重走部门审核 + COO 终审两级流程。 历史版本永久留存,可随时在受控区调阅。
  • 含已放行内容的订单也不能被删除——防止有编辑权限的人抹掉已终审的核查证据。

5.4 退回与整改#

  • 任一审核节点都可以退回,退回必须填写整改要求(不填时「退回」按钮是灰的)。
  • 被退回的条目会在工作台「待我处理」和待办列表中以红色显示整改要求。
  • 责任人按要求替换/补充附件后重新提交即可;重新提交时旧的退回意见会被清空。
  • 审核通过时填写的意见同样会记入操作日志,可事后追溯。

5.5 撤回#

提交后、审核完成前,提交人可点「撤回」把条目收回,修改后重新提交。 如果 COO 恰好在同一时刻放行,系统会保证只有一方生效,不会出现"既已放行又已撤回"的矛盾状态。

5.6 职责分离#

本部门有其他审核人时,不能审核自己提交的资料。 遇到这种情况,系统不会显示「通过/退回」按钮;若通过其他途径尝试,会返回明确提示:

职责分离:不能审核本人提交的内容,请由本部门其他审核人处理

(注:COO 终审人与管理员不受此限制,属合规政策上的既定安排,详见《上线待办与风险记录》P2 条目。)

5.7 超期#

资料包可以配置截止日期。超过截止日期仍未放行的条目,在工作台和待办任务里以红色标注, 工作台的「超期」计数也会同步显示。

6. 分角色操作指引#

6.1 提交人(采购 / 物流 / 财务 / 生产等责任人)#

职责:上传自己负责的资料、发起审核、处理退回整改。

每天怎么开始#

  1. 登录后先看工作台:
    • 「待我处理」数字点进去就是待办列表;
    • 下方「需要关注」列出被退回的条目与红色的整改要求;
    • 「资料包进度」显示你负责的每个资料包的完成度与状态,超期的名称标红。
  2. 或者直接看铃铛里的新通知。

上传并提交(资料包线)#

  1. 侧边菜单 →「资料包」;可用关键词、责任部门、状态三个条件筛选,快速定位。
  2. 点某个资料包的「详情」进入。页面顶部会显示该包的核查重点与截止日期——上传前请先读一遍核查重点。
  3. 若当前版本已放行或需要重新做,点「发起新版本」新建一个版本。
  4. 在附件区拖拽或点击选择文件上传(可多选),需要时填写批次号。
  5. 附件齐了之后点「提交审核」并确认,状态变为待部门审核。

上传并提交(订单线)#

  1. 侧边菜单 →「客户订单」→ 用订单号/客户/产品搜索定位 → 点「详情」。
  2. 在订单详情里找到对应的资料包实例;若还没添加,点「添加资料包」选择需要的资料包。
  3. 弹窗里的责任人默认带出该资料包的责任人——这一项决定了谁能往里传附件。 一张订单要凑齐 18 类证据,各类材料本就由各自的责任人上传,所以加进来即等于 把这份材料派给了他(对方会收到通知,待办里也会出现这条)。 要自己传就把责任人改成自己。
  4. 在该实例的附件区上传附件,可填批次号。
  5. 点「提交审核」。

展开某条资料包实例却看不到上传区,通常就是这条被派给了别人。 让建单人在「添加资料包」里改派,或请对应责任人来传。

处理退回#

  1. 待办列表中被退回的行会显示红色的整改要求。
  2. 点进去,按要求替换或补充附件。
  3. 重新点「提交审核」。(注意:在审核中或已退回状态下重新上传附件,系统会自动把状态放回「待部门审核」。)

撤回#

提交后发现传错了,在条目上点「撤回」,修改后重新提交。

提交人做不了的事#

不能审核(包括自己的和别人的)、不能进受控区、不能看操作日志与组织管理。这些是设计如此。

6.2 部门审核人(采购经理 / 生产经理 / 工程经理等)#

职责:审核本部门责任范围内的资料,把好第一道关。

处理待审#

  1. 从铃铛通知或「待办任务」进入待审条目(状态为「待部门审核」)。
  2. 待办列表可看到:资料包名、版本号、状态、责任部门、责任人、截止日期(超期标红)、附件数、退回意见、提交时间。
  3. 点进条目,逐份点开附件在线预览核对,对照该资料包的核查重点逐条检查。
  4. 给出结论:
    • 通过 → 状态转为「待COO终审」,COO 会收到通知;
    • 退回 → 必须填写整改要求,责任人会收到通知并看到红色提示。
  5. 通过与退回的意见都会记入操作日志。

注意事项#

  • 职责分离:本部门有其他审核人时,你提交的内容你自己审不了(按钮不会显示)。
  • 你只能看到与操作本部门责任范围内的资料包;跨部门的内容不在你的可见范围。
  • 订单线还受工厂授权约束:只能看到你被授权的工厂的订单。
  • 你可以进入受控区只读查看已放行内容,但不能看操作日志、不能进组织管理、不能导出订单清单。

6.3 COO 终审人(合规负责人)#

职责:终审放行、全局把关、对外交付。

终审#

  1. 「待办任务」中处理状态为「待COO终审」的条目(也可从铃铛进入)。
  2. 逐份预览附件复核。
  3. 结论:
    • 放行 → 状态变「已放行」,该版本即刻锁定为只读,进入受控区并参与当日 NAS 归档;
    • 退回 → 必须填写整改要求,退回给责任人重做。
  4. 放行后要变更:只能新建版本重走两级审核,历史版本永久留存。

全局视图#

  • 工作台可看到全部部门、全部工厂的完成度、已放行数、附件总数、超期数与资料包进度。
  • 「客户订单」可查看所有授权工厂的订单及其完成度。

对外交付(核查回函常用)#

需要什么从哪里拿得到什么
归档清单工作台 →「导出 Excel」archive_list.xlsx,覆盖两条线并有「类型」列区分
某张订单的资料清单客户订单列表 → 该行「导出 Excel」order_{订单号}.xlsx
某张订单的完整附件包客户订单列表 → 该行「导出 ZIP」order_{订单号}_archive.zip,内含 _manifest.xlsx 交付清单
受控区某个版本 / 订单实例的附件包受控区 → 展开该条 →「下载 ZIP」controlled_*.zip,内含 _manifest.xlsx

上表所有导出都是点了就下载。只有一种情况例外,见下。

导出排队与「我的导出」#

导出(尤其是整包 ZIP 和大范围的日志)很吃机器。同时导出的人多了以后, 系统会限制同时进行的导出数量——轮不上的那次不会失败,而是转成后台作业, 界面提示「导出已排队,完成后可在『我的导出』下载」。你不用守着页面,也不用重试。

侧边菜单 →「我的导出」:

列说明
类型哪一种导出(归档清单 / 订单清单 / 订单 ZIP / 受控 ZIP / 操作日志)
状态排队中 → 进行中 → 已完成 / 失败
文件、大小完成后出现,点即可下载
失败原因失败时说明为什么,不是只给一个红叉
  • 完成后会有通知(顶栏铃铛),不必守在这一页;页面右上角有「刷新」。
  • 产物保留 24 小时,过期自动清理,请及时下载;记录可以自行删除。
  • 这一页只显示你自己提交的导出。

NAS 归档#

「NAS 归档」页上下两块:上面是同步状态(上次同步时间、成功/失败数量、待同步数量、 连通状态),下面是同步记录。可手动触发同步;归档目标(NAS 地址与密钥)的配置 权限在管理员手里。

每日凌晨的自动同步已恢复正常(此前有一个会让它被静默跳过的缺陷,2026-08-26 已修复 并跨过真实触发时刻实测),不需要再每天手动点一次。日常只要看一眼「待同步」是不是 在正常回落即可。

同步记录里的字段:

列含义
时间该批次的开始时间
触发方式自动(每日凌晨定时)/ 手动(有人点了「立即同步」)
状态成功 = 全部归档;部分成功 = 有文件没传上去,需要跟进;失败 = 整批未完成;进行中 = 还在跑
成功/总数该批次实际归档数 / 应归档数;有失败时会在后面用红字标出失败件数

归档是核查证据的异地副本,漏掉一天就是漏掉当天放行资料的副本。

6.4 审计查看人(内审 / 外部核查配合)#

职责:只读调阅与举证导出。不能上传、不能审核、不能删除任何内容。

受控区(主要工作面)#

  1. 侧边菜单 →「受控区」。这里只显示 COO 已放行的内容,覆盖两条线: 资料包已放行版本 + 订单资料包已放行实例。
  2. 展开任一条可看到其全部附件:文件名、批次号、大小、上传时间;可在线预览或单个下载。
  3. 点「下载 ZIP」可把该条的全部附件打包下载,包内附 _manifest.xlsx 交付清单。
  4. 列表分页显示并给出总条数。

操作日志(举证材料)#

  1. 侧边菜单 →「操作日志」。
  2. 可按以下条件组合查询:
    • 操作人(姓名/用户名关键词)
    • 目标(资料包编号、订单号、文件名等关键词)
    • 事件域(auth 认证 / package 资料包 / attachment 附件 / review 审核 / version 版本 / nas 归档 / export 导出 / org 组织)
    • 时间范围
  3. 表格列:时间、事件域.动作、操作人、IP、目标、说明。
  4. 点「导出 Excel」得到 audit_logs.xlsx。

两条很重要的规则

1. 导出内容与当前筛选条件严格一致——你在界面上看到的是什么条件,导出的就是那个条件的全部记录, 不会出现"界面 53 条、导出 2396 条"这种对不上的情况。 2. 不会静默截断。界面单次最多显示 1000 条;若命中更多,页面顶部会出现黄色提示条明确告诉你 「共命中 N 条,当前仅显示最新 M 条」。导出则包含符合条件的全部记录, 上限 10 万条,超过会直接报错要求你缩小时间范围——而不是给你一份"看起来完整、实际被截断"的文件。

其他可见范围#

  • 「客户订单」「资料包」只读可看(不能新建、不能上传、不能删除);
  • 「NAS 归档」只读可看同步状态(不能触发同步、不能改配置);
  • 可导出归档清单与订单资料清单;
  • 不可进入「待办任务」与「组织管理」。

导出文件的可靠性#

所有导出表格中的编号、订单号、MD5 等长串一律以文本存放, 不会被 Excel 自动转成科学计数法或抹掉前导零——否则导出的清单会与系统记录对不上, 而核查方并不会知道是 Excel 改的。

6.5 系统管理员(IT)#

职责:账号/部门/工厂/资料包配置、NAS 归档配置、安全维护。

涉及服务器、备份、升级、故障处理的内容见另一份《部署与运维手册》。

组织管理 →「部门」#

  • 新建部门:填部门编号(≤32 字符)与中/英/泰三语名称。
  • 编辑部门:可改三语名称(编号不可改)。

组织管理 →「工厂」#

  • 工厂是订单数据的隔离边界:账号必须被授权某工厂,才能看到该工厂的订单。
  • 新建工厂:编号 + 三语名称。
  • 启用/停用(带二次确认):
    • 停用表示不再接新订单——停用后无法在该工厂下新建订单;
    • 停用不会隐藏历史数据:该厂已有订单、待办、统计、归档导出全部照常可见。

组织管理 →「用户」#

  • 新建用户:用户名(≤64)、姓名、初始密码(≥6 位)、角色、所属部门、授权工厂(可多选)。
  • 编辑用户:改姓名/角色/部门/工厂授权。
  • 停用/启用(带二次确认):停用后该用户立即无法登录,已登录的会话也会在下次请求时被踢出并显示 「账号已被停用」;历史操作记录全部保留。
  • 重置密码:生成一次性临时密码,只显示一次,请当场记下并单独告知本人。 谁重置了谁的密码会记入操作日志。
  • 防自锁保护:系统会拒绝停用你当前登录的账号,也会拒绝停用或降级最后一个启用状态的管理员。

组织管理 →「安全设置」#

  • 轮换 JWT 登录密钥:用于怀疑令牌泄露或需要强制全员下线的场景。 轮换后所有人(包括你自己)都需要重新登录,操作有二次确认,并记入操作日志。

资料包配置(「资料包」页)#

管理员在资料包列表可以新增与编辑资料包:

字段说明
编号如 COO-01,≤32 字符,创建后不可修改
名称(中/英/泰)三语各 ≤255 字符;泰国工厂用户读的就是泰文那一列,请填全
排序列表显示顺序
责任部门决定哪个部门的审核人负责审核
责任人负责上传的提交人
是否必需影响完成度统计
核查重点会显示在资料包详情页顶部,提交人与审核人都会看到
截止日期如 2026-10-15,超期在工作台与待办中标红
状态启用 / 停用

NAS 归档配置(「NAS 归档」→「NAS 配置」,仅管理员)#

可配置:接入方式(S3 兼容接口 / 本地挂载目录)、端点地址、Access Key / Secret Key、 存储桶、区域、HTTPS 开关、每日自动同步时间、自动同步开关。

三条必须知道的规则

1. 保存前务必先点「测试连接」。改错地址或密钥而不试连,要等到当晚自动同步失败才会暴露, 而那意味着当天该归档的核查证据没有留存。测试会区分"地址不通 / 密钥无效 / 桶不存在"给出具体原因,且不写库。 2. Secret Key 只写不读:界面和接口都只返回掩码,留空提交表示保持不变。 3. 更换归档目标会触发全量重新归档。保存后系统会把全部历史附件重新标记为待归档, 并在结果里告诉你数量。这是必需的——新 NAS 必须拿到完整副本,否则它上面只有清单而没有文件。 首次同步的数据量等于历史全部附件,请安排在业务低峰执行。

配置保存后立即生效,不需要重启服务;每次变更都会写入操作日志(记录归档目标、同步时间与重新归档数量,不含密钥)。

操作日志#

与审计查看人相同的查询与导出能力(见 6.4)。

7.1 五种导出#

导出物入口文件名可用角色
操作日志操作日志页 →「导出 Excel」audit_logs.xlsx审计查看人、管理员
归档清单工作台 →「导出 Excel」archive_list.xlsxCOO 终审人、审计查看人、管理员
订单资料清单客户订单列表 → 行内「导出 Excel」order_{订单号}.xlsxCOO 终审人、审计查看人、管理员

7.2 ZIP 包里有什么#

  • 按 NAS 归档同一套命名规则组织的附件文件——三处规则一致,便于与 NAS 上的归档交叉核验;
  • 同一目录下有同名文件时(如多个供应商各自的「发票.pdf」),系统会自动追加内容哈希前 8 位加以区分, 不会互相覆盖导致静默缺件;
  • 根目录下的 _manifest.xlsx 交付清单:列出包内文件名、上传原名、字节数、MD5,与包内实际内容逐条对应。

大包导出已做过优化:含近百 MB 附件的订单包,导出通常在几秒内完成。

7.3 关于 Excel#

  • 所有单元格强制为文本类型:长数字串(内部 ID、MD5、纯数字订单号)完整保留,不会变成科学计数法;
  • 以 = 开头的内容原样显示、不会被 Excel 当公式执行(防公式注入);
  • 表头冻结、自动筛选、按内容计算列宽,打开即可用;
  • 时间列为站点时区并带明确偏移(如 2026-08-23 14:51:49+07:00),表头标注「时间(站点时区)」。

系统当前没有导入功能。如需按 Excel 模板批量导入订单/资料包,需另行开发。
