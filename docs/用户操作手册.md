# COO 资料收集平台 · 用户操作手册(分角色)

对应《需求规格说明书(一期)》8.3 节交付物。界面支持中文/English/ไทย,右上角可切换并记住选择。

## 0. 通用操作

- **登录**:浏览器打开系统地址,输入账号密码。连续 5 次密码错误将锁定 30 分钟;忘记密码联系管理员重置(重置后管理员会告知一次性临时密码,登录后请立即在右上角「修改密码」中更换)。
- **会话**:登录有效期 8 小时,过期自动跳回登录页。
- **通知**:右上角铃铛显示待办通知(提交、退回、放行等),点击条目直达对应页面。
- **待办**:「待办任务」页汇总"待我处理"事项,**超期项以红色标注截止日期**。
- **附件预览**:PDF 与图片可在线预览(点击附件名);其他格式(Word/Excel/ZIP 等)点下载后本地查看。

### 业务流程总览

> 责任人上传 → 部门审核 → COO 终审 → 受控归档(版本锁定) → 核查调阅

- 审核中或已放行的资料,一旦重新上传/删除附件,状态自动**回退至「待部门审核」**,原审核结论作废(已放行且锁定的版本不可再改,只能新建版本)。
- 任何退回都必须填写整改要求;被退回后整改重新提交即可。

## 1. 提交人(采购/物流/财务/生产等责任人)

**职责**:上传本人负责的资料,发起审核,处理退回整改。

1. **查看任务**:登录后看「工作台」的"待我处理"与「待办任务」列表;被退回的条目会显示红色整改要求。
2. **上传资料(资料包线)**:资料包 → 进入本人负责的资料包 → 选择/新建版本 → 上传附件(可多选;支持 PDF/Office/图片/ZIP 等,单文件 ≤100MB;可填订单号/批次号)。
3. **上传资料(订单线)**:客户订单 → 进入订单 → 对应资料包实例 → 上传附件。
4. **提交审核**:附件齐后点「提交审核」,状态变为「待部门审核」。
5. **处理退回**:按整改要求替换/补充附件后重新提交(重新上传即自动回到审核队列)。
6. **撤回**:提交后未审完可撤回,修改后重新提交。

## 2. 部门审核人(采购经理/生产经理等)

**职责**:审核本部门范围内的资料。

1. 「待办任务」或铃铛通知中看到「待部门审核」条目,点击进入。
2. 审核页可直接**在线预览附件**逐份核对(参考资料包的"核查重点")。
3. 结论:**通过**(转呈 COO 终审)或**退回**(必须填写整改要求,退回给责任人)。
4. 注意:本部门有其他审核人时,不能审核自己提交的资料(职责分离)。

## 3. COO 终审人(合规负责人)

**职责**:终审放行、全局把关。

1. 「待办任务」中处理「待 COO 终审」条目;可全局查看所有部门资料与统计。
2. 结论:**放行**(状态变「已放行」,该版本即刻**锁定为只读**,进入受控区并参与 NAS 归档)或**退回**(必填整改要求)。
3. 放行后如需变更:只能新建版本重走两级审核,历史版本永久留存。
4. 可在「归档清单导出」「订单导出」中导出 CSV 清单与 ZIP 附件包,供核查回函使用。

## 4. 审计查看人(内审/外部核查配合)

**职责**:只读调阅与举证导出,不可上传/审核/删除。

1. **受控区**:仅显示 COO 已放行的版本,可查看与下载(含整版本 ZIP 打包下载)。
2. **操作日志**:可按操作人、时间范围、目标(资料包编号/订单号/文件名)、事件域组合查询,并导出 CSV(Excel 可直接打开)作为佐证材料。
3. **归档清单**:工作台/导出入口可导出资料包归档清单 CSV。

## 5. 系统管理员(IT)

**职责**:账号/部门/工厂/资料包配置、NAS 同步、安全维护。

1. **组织管理**:
   - 部门:新建、编辑名称(中/英/泰)。
   - 工厂:新建、启停(工厂是订单数据的隔离边界,账号须授权工厂才能看到对应订单)。
   - 用户:新建(设定角色、部门、工厂授权)、**编辑**(改角色/部门/授权)、**停用/启用**(停用立即禁止登录,历史操作记录保留)、重置密码(一次性临时密码,只显示一次)。
   - **安全设置**:轮换 JWT 登录密钥——怀疑泄露或需强制全员下线时使用;轮换后所有人(含自己)需重新登录。
2. **资料包配置**:新增/编辑/停用资料包,配置编号、三语名称、责任部门、责任人、核查重点、截止日期、是否必需。
3. **NAS 归档**:查看同步状态(上次时间、成功/失败清单、连通状态),手动触发同步;每日 01:00 自动同步。
4. **操作日志**:与审计查看人相同的查询与导出能力。

## 附:状态说明

| 状态 | 含义 |
|------|------|
| 草稿 | 未提交,可自由编辑附件 |
| 待部门审核 | 已提交,等待部门审核人处理 |
| 待COO终审 | 部门已通过,等待 COO 终审 |
| 已放行 | COO 终审通过,版本锁定只读,进入受控区 |
| 已退回 | 审核未通过,需按整改要求处理后重新提交 |
| 已撤回 | 提交人主动撤回,修改后可重新提交 |
